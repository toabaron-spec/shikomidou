 RULES

仕込みツールを使うときのマナーと注意点

「ネタばらしまでが演出」。仕込みを楽しい思い出にするためのルールと、やってはいけない使い方。

はじめての起動のしかた

個人開発の無料ソフトのため、初回は Windows の確認画面が出ます。次の手順で起動できます。

  1. ZIPをダウンロードして展開するダウンロードしたファイルを右クリック →「すべて展開」。
  2. 中の .exe をダブルクリック「WindowsによってPCが保護されました」という青い画面が出ることがあります。
  3. 「詳細情報」をクリック画面の左上あたりにある小さい文字のリンクです。
  4. 「実行」をクリックアプリが起動します。2回目からは確認画面は出ません。

よくある質問

ウイルス対策ソフトに「危険」と言われました

このツールは Python で作り、PyInstaller という仕組みで1つの .exe にまとめています。この方法で作ったソフトは、中身に問題がなくても誤ってウイルス扱いされることがあります（誤検知）。ダウンロードはこのサイトのボタン（GitHub の公式配布ページ）からのみ行ってください。

Mac やスマホで使えますか？

いまは Windows 10 / 11（64bit）だけに対応しています。Mac・Linux・スマホ・32bit版 Windows では動きません。

本当に無料ですか？

はい、すべて無料です。サイトの運営費は広告収入でまかなう予定です。

景品の抽選やプレゼント企画に使ってもいいですか？

いいえ。結果を仕込めるツールなので、本物の抽選・懸賞・キャンペーンには使わないでください。参加者が「仕込みかも」と分かって笑える場、ネタだと明かす前提の場でお楽しみください。詳しくはマナーと注意点をご覧ください。

アンインストールはどうすればいいですか？

インストールしていないので、展開したフォルダごと削除すれば完了です。
